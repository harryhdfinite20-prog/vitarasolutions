# Vitara Solutions — Simple Frontend Website

This website uses only **HTML, CSS, and a tiny amount of vanilla JavaScript**. There is no Python runtime, Node.js, npm, backend, database, build step, or form service.

## Run it locally
1. Extract this ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. That's it. No server is required for this static frontend preview.

The mobile menu and FAQ accordion use `assets/script.js`. Fonts and photos load from external URLs, so an internet connection is needed for those assets.

## Files
- `index.html` — entire one-page website
- `assets/style.css` — all styling and responsive design
- `assets/script.js` — tiny mobile menu and FAQ behavior

## Before publishing
- Replace `hello@vitarasolutions.com` with your real email address if needed.
- Images are externally hosted from Unsplash; replace with properly licensed local assets if desired.
- This is frontend-only: there is no contact form or backend. The CTA opens the visitor's email app using a `mailto:` link.
- Deploy the folder on Vercel as a static site: framework preset `Other`, no build command, root directory as project root.


Brand palette: #1b52a4, #00a2e5, #fec40d, #f58020, #d64246, #098855. A light/dark theme switch is included in the navigation; the selected theme is remembered in the browser.
